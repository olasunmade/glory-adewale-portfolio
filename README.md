# Glory Adewale — Social Media Manager Portfolio

A single-page portfolio site built from Glory Adewale's Notion portfolio content, styled after a
dark navy / accent-color case-study aesthetic.

## Structure
- `index.html` — page markup (hero, about, experience timeline, case studies, freelance work, reviews, contact)
- `style.css` — dark navy theme, responsive layout
- `script.js` — mobile nav, scroll reveal animations, stat counters, case study accordion

## Run locally
Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy
Static site — deployable as-is to Netlify, Vercel, GitHub Pages, or any static host.
